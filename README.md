# Dental Care - Dentist & Dental Clinic Website

A modern, responsive, and fully customizable Dental Clinic website template built with React and Vite.

## ✨ Features
- **Video Hero Section**: High quality video background hero header.
- **Dynamic Clinic Configuration**: Customize clinic name, phone, WhatsApp, email, address, and timings in one single file (`src/siteConfig.js`).
- **Instant WhatsApp Appointment Booking**: Direct appointment scheduling that formats booking details and opens WhatsApp with pre-filled messages.
- **Get In Touch Contact Form**: Interactive inquiry form routing to WhatsApp and saving inquiries locally.
- **Floating WhatsApp Chatbot**: Fixed bottom-right quick chat button on all pages.
- **20+ Inner Pages**: Services, Case Studies, Team Members, Image & Video Galleries, FAQs, and more.
- **SEO & Performance Ready**: Fast load times, responsive on all screen sizes.

## 🚀 Quick Start

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```

## 🛠️ Configuration
Open `src/siteConfig.js` to change:
- Clinic Name & Tagline
- Contact Numbers & WhatsApp Number
- Clinic Address & Google Maps link
- Operating Hours & Social Media links

## 🌐 Deploy on Vercel
1. Import this repository into Vercel.
2. Framework Preset: **Vite** (auto-detected).
3. Build Command: `npm run build`.
4. Output Directory: `dist`.
5. Click **Deploy**!
